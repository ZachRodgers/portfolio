# Stockhub inventory preview

The first section uses the product inventory renderer and its UI components in an isolated static iframe. Cedar & Bolt is a fictional hardware retailer; all 30 item descriptions, identifiers, quantities, bins, and warehouses are invented in `scripts/stockhub-demo/local.ts`. No customer records, database connection, credentials, or server routes are included. Fetch is replaced inside the iframe with a local adapter that rejects unknown endpoints. Telemetry is disabled.

Run `npm run build:stockhub-demo` to rebuild. `STOCKHUB_SOURCE` selects the product's `apps/web` directory. The script currently uses the existing compiled CSS at `.next/static/css/app/layout.css` and the bundler installed in `/home/Zach/Repos/mission-control/node_modules/esbuild`. Product dependencies must be installed. Ordinary portfolio builds need neither checkout. Source hashes and dependency license notices accompany the static bundle.

Search, column sorting, warehouse selection, row details, totals, pagination, and spreadsheet export use the product components. Replay reloads the preview. The shell uses the original ProtectedSidebar, AppSidebar, warehouse selector, breadcrumb, account menu, theme provider, warehouse asset, and Geist font files. Only Next navigation and image delivery are adapted for static hosting. The preview renders at 1440 × 900 and scales as one unit. Order navigation is outside this first section; no order data is imported. The next three sections and rationale content remain for subsequent passes. The rationale button is intentionally disabled.

The demo-only branding adapter uses the portfolio StockHub wordmark (cropped to its icon when collapsed), with Zach as the fictional account. The runtime uses the product React dependencies. Product hover, focus, transition, and menu classes are preserved in the compiled product stylesheet. Navigation to later workflows remains outside this inventory section.

The portfolio preview displays eight rows per page, uses Toronto and Ottawa locations, narrows the description column, and hides the Bin table column; item details retain the bin. These presentation adaptations are applied during the demo build.
